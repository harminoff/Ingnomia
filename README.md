# Ingnomia

Ingnomia is a colony-management game that began as an independent remake of [Gnomoria](https://store.steampowered.com/app/224500/Gnomoria/). The original Ingnomia project was created by **Ralph Schurade (@rschurade)**: [upstream repository](https://github.com/rschurade/Ingnomia).

This community fork is primarily a **user-interface update**. It modernizes the game interface with Qt 6 and RmlUi, including a unified HUD, detachable windows, and redesigned management screens for areas such as inventory, population, stockpiles, workshops, and agriculture.

## Gameplay changes in this fork

Gameplay changes are limited compared with the UI work. They include:

- Per-plot crop choices and saved planting queues, with repeat and quantity options.
- A refreshed, seeded tutorial scenario and starting setup.

## Download

Windows builds are published on this fork's [Releases page](https://github.com/harminoff/Ingnomia/releases). The original project is also available on [Steam](https://store.steampowered.com/app/709240/Ingnomia/).

Pushing a `v*` tag runs the Windows build workflow and publishes the packaged game as a GitHub release.
